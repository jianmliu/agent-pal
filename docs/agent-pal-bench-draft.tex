\begin{abstract}

Persistent role-playing games combine dialogue comprehension, spatial exploration, cross-scene causality, and resource management. We introduce \textbf{Agent-PAL-Bench}, a text-based agent benchmark built on a headless execution environment for \emph{The Legend of Sword and Fairy}. Agents issue structured tool calls and receive textual game-state feedback; gameplay video is not an agent input. Beyond the default \nolinkurl{assist} (L1) layer that exposes high-level semantic tools, the environment implements a \nolinkurl{--pure} mode that exposes only low-level protocol primitives (L0) and in-session dynamic self-coding (\nolinkurl{run_code} and \nolinkurl{module_reload}). The reviewed working catalog contains 23 tasks and 67 planned task--seed episodes. Tasks specify starting states, state-based goals, budgets, information conditions, and reference trajectories. A current-build audit reaches the goal on 59/67 reference trajectories, exposing release-blocking failures rather than model errors. A separate, frozen two-task audit repairs missing appearance cues and premature goal detection, calibrates action budgets, and evaluates three built-in cloud agents and one externally scaffolded agent on game seed 42. All eight evaluation episodes exhaust their action budgets without success and pass trajectory replay; calibration and reference successes are reported separately. In addition, we validate the \nolinkurl{--pure} mode end-to-end under deterministic lockstep (\nolinkurl{--seed 1}) across three external agents (Argon, GPT-6.1-Sol, and Claude Opus 5.5): operating strictly from \nolinkurl{SMSG_*} state packets and \nolinkurl{CMSG_*} primitives, the three agents independently synthesize 731-line, 135-line, and 1,427-line runtime libraries in session scope (spanning bytecode-graph BFS pathfinders, connected-component dungeon planners, resistance-adaptive combat engines, and menu state machines), each completing all 11 chapters from a new game to the final boss (\nolinkurl{Baiyue}, 32,760 HP) across sequential save checkpoints (\nolinkurl{Slots 1–99}). Furthermore, across four targeted behavioral and ablation studies on \textbf{Dali Rain Altar (\nolinkurl{classic48-rain-orbs})}, \textbf{Baihe Village Medicine (\nolinkurl{classic10-baihe-medicine})}, \textbf{Final Boss Baiyue (\nolinkurl{baiyue-single-origin})}, and \textbf{Yangzhou Purple Gold Gourd (\nolinkurl{classic19-yangzhou-gourd})}---paired with a 22-question closed-book prior quiz (\nolinkurl{bench quiz}), cross-seed replication, budget expansion, and a counterfactual no-cheese ablation stripping \nolinkurl{Jiushen}, \nolinkurl{Qian Kun Yi Zhi}, and \nolinkurl{Yingu}---we evaluate 10--12 frontier and open-weight cloud models, uncovering: (1) how 45\ensuremath{^\circ} isometric chiral symmetry ambiguity triggers 100K-token deductive loops in reasoning LLMs and how 1-step epistemic probes and per-turn token circuit breakers resolve them; (2) how closed-book quizzes separate pretraining walkthrough contamination from genuine zero-shot room-by-room discovery and expose single-cutoff truncation illusions; (3) a two-layer prior structure (walkthrough meta priors versus domain mechanics priors), recency-biased overcorrection during in-context retry learning, and the delayed batch-execution credit-assignment trap (\nolinkurl{ΔHP = x1 + x2 + x3}) versus controlled-variable linear elimination in turn-based combat; and (4) how partial false priors (\nolinkurl{gourd#q4} well-side misremembering) induce confirmation-bias search stalls (82 versus 22 calls) on a 15-scene detective chain, while a zero-prior agent recovers from post-victory loot omission and re-purposes its earlier four-rooftop chase topology (\nolinkurl{Episodic Spatial Graph Reuse}) to reach an elevated observation point. The findings identify observation fidelity, context retention, prior contamination, metacognitive stopping rules, tool-abstraction layer, and self-coded architectural divergence as measurement concerns. They do not establish a regional model advantage, a causal success-rate gain from the repairs, or a measure of planning alone.

\end{abstract}

\section{Introduction}

Knowing where to find the Water Spirit Orb is different from finding the relevant characters, retaining a necessary item, crossing scenes, and completing an exchange within an action budget. Knowing that a final boss requires damage is different from conserving resources through prerequisite fights and adapting when a healer is silenced or incapacitated. A persistent game lets us examine how an agent turns information into consequential actions.

We use a Chinese fantasy RPG because dialogue, character relationships, implicit prerequisites, map mechanisms, equipment, and consumables interact in one authored world. Whether familiarity with Chinese game language and culture improves situated decisions is an open research question. Model developer location does not measure that familiarity. Scale, pretraining, reasoning budget, tools, information access, and agent scaffolding must be controlled before attributing differences to cultural knowledge.

This paper contributes: (1) a working collection of replayable RPG segments, including same-goal starting-state variants, causal item chains, and synthetic combat configurations; (2) a protocol based on fixed saves, game seeds, virtual time, state predicates, and action replay; (3) explicit tool and hint conditions, distinguishing the built-in white-box high-level tool layer (\nolinkurl{assist} L1) from the low-level protocol and dynamic self-coding layer (\nolinkurl{--pure} L0 + \nolinkurl{run_code}/\nolinkurl{module_reload}); (4) a two-task development audit showing how missing observations, an early-success predicate, and context policy complicate failure attribution, complemented by an end-to-end \nolinkurl{--pure} self-coding playthrough from new game to final credits that validates L0 protocol completeness; and (5) four targeted cognitive-behavioral and counterfactual ablation studies across spatial symmetry puzzles (\nolinkurl{classic48-rain-orbs}), multi-stage open exploration (\nolinkurl{classic10-baihe-medicine}), high-pressure boss combat (\nolinkurl{baiyue-single-origin}), and a 15-scene detective chain (\nolinkurl{classic19-yangzhou-gourd}), quantifying deductive loop traps, zero-shot exploration overhead, partial false-prior belief updating, episodic spatial graph reuse, in-context retry evolution, and batch-execution credit assignment. The implemented environment, development validations, targeted behavioral slices, and the proposed full-catalog inferential study have different evidential status.

\section{Related Work}

\href{https://arxiv.org/abs/2308.03688}{AgentBench} evaluates agents across interactive environments. \href{https://arxiv.org/abs/1806.11532}{TextWorld} supports state tracking and controlled generation of text games; our tasks use an existing authored RPG. \href{https://arxiv.org/abs/1909.05398}{Jericho} studies human-authored interactive fiction. Agent-PAL-Bench shares its exploration demands and also exposes party, equipment, consumable, and combat systems. \href{https://arxiv.org/abs/2203.07540}{ScienceWorld} distinguishes factual recall from applying knowledge in an interactive environment. \href{https://arxiv.org/abs/2010.03768}{ALFWorld} connects text and embodied environments, highlighting the distinction between text-mediated decisions and visual understanding. \href{https://arxiv.org/abs/2406.06613}{GameBench} and \href{https://arxiv.org/abs/2411.13543}{BALROG} provide broader game-based comparisons.

RPG agency itself is not new: the \href{https://arxiv.org/abs/2603.15563}{PokeAgent Challenge} includes competitive battling and RPG speedrunning, and \href{https://arxiv.org/abs/2604.08340}{PokeGym} evaluates visually driven long-horizon tasks and adaptation. Our scope is a Chinese-language authored RPG with inspectable task predicates and structured text interaction. We make no priority claim for RPG planning, persistent worlds, or game-agent evaluation. Our reported scores cannot be compared directly to visual or differently scaffolded benchmarks.

\section{Environment and Tasks}

\subsection{Interaction and replay}

Each episode runs an isolated game process from a new game, a classic RPG save, or a fixed benchmark save slot, with a game random seed. Tools include \nolinkurl{observe}, \nolinkurl{map}, movement, interaction, dialogue advance, menu choices, items, spells, and battle actions. Game simulation is paused between calls; advancing actions move virtual time, whereas observation and reference-material queries do not. Model inference latency therefore does not itself advance the game. Wall-time limits remain a separate harness constraint. Saves and map memory are isolated between episodes. Video is for human inspection, not the B/C-tier agent or grader. The reviewed task catalog opens no visual A-tier tasks.

A task defines its start, goal predicates, optional milestones and failure conditions, budgets, and tools. The grader reads state such as scene visits, inventory, event-object state, battle outcomes, and dialogue history. \nolinkurl{check} replays references. \nolinkurl{verify} replays logged actions and compares per-step grading state and terminal game outcomes. It does not rerun model inference or independently validate token accounting, cost, or model-side stopping causes. Standard replay is not a proof that all observation text was complete or accurate; the appearance audit adds native observation checks and selected response-equivalence checks. A successful reference is a feasibility witness for that version and seed, not an optimal policy or a model result.

The current general-task runner records a Git revision label, task versions, seeds, prompt version, and logs; battle-scored runs additionally record runtime/asset and task/save fingerprints. General-task runs do not automatically receive all those hashes. The frozen appearance experiment therefore supplies separate manifests. A \nolinkurl{-dirty} label alone cannot identify the exact executable, assets, or task contents.

\subsection{Information and context conditions}

B provides structured text tools; C adds walkthrough and atlas access. Independently, \nolinkurl{standard} suppresses some script-derived purpose/requirement hints that \nolinkurl{full} exposes. Standard is not a guarantee of pixel-equivalent information: structured coordinates, IDs, navigation categories, and state summaries remain abstractions. Item-effect information may still be present under standard. \nolinkurl{observe(full=true)} requests expanded observation; it is distinct from the environment's \nolinkurl{hints=full} setting.

The built-in loop retains the full text of only the latest \textbf{six tool results}, replacing older results with placeholders while preserving assistant text and call records. An earlier clue may disappear unless the agent records or reacquires it. Claude CLI manages its own context. Built-in usage is checked against the token budget after each model turn; external CLI usage is merged only at episode end, so the task token cap is not enforced incrementally there. These differences require separate reporting. Translating only the brief does not remove Chinese game dialogue; an English-only observation condition and comprehensive name masking are not implemented.

\section{Metrics and Proposed Experimental Protocol}

The implemented primary score is task success averaged across recorded seeds and then equally across tasks with results. \nolinkurl{complete} indicates whether planned episodes are present; incomplete runs must not enter a formal ranking. For runs consisting entirely of Baiyue battle-scored tasks, ties in success are broken by \textbf{mean battle rounds among wins}, lower first. Ordinary runs instead use mean monetary cost among successes; mixed scoring has no meaningful common efficiency tie-break. Tool calls are not combat rounds. No-success efficiency statistics are undefined, not zero.

Diagnostic metrics include milestone progress, median calls to success, invalid-call rate, virtual time, tokens, and recorded cost. Invalid rate is total invalid calls divided by total tool calls, not an average of episode percentages. Expected movement/interaction interruptions caused by battle or dialogue are soft stops and are excluded from invalid calls. Failure progress counts achieved milestones divided by one plus the number of milestones; success sets it to one. Neither progress nor reference-relative call efficiency is an independent capability score. Zero recorded local/cloud cost can mean unpriced usage, not zero computation cost.

\section{Development Audits and Exploratory Results}

\subsection{Main working-tree reference audit}

On 16 October 2026, the reviewed 23-task working tree passed schema validation and no-engine tests. Full \nolinkurl{check --jobs 2} reached the goal on \textbf{59/67 reference trajectories}. Five Baiyue failures requested Qian Kun Yi Zhi from a member without that spell at the observed command window: fragile-stocked seed 42, mana-budget seed 43, origin seed 43, and sustain-no-wine seeds 42/43. Three tower references missed the target: tower-chain seeds 43/44 and tower-gate seed 43. These are reference failures, not model scores; their root causes and repairs remain open. Historical Baiyue reference successes on older builds do not override this current-build result. The one-seed palace reserve reference passed, but remains a development pilot.

\subsection{Local-model pipeline pilot and historical evidence}

Qwen2.5-3B (\nolinkurl{ollama:qwen2.5-bench-32k:3b}), built-in B-standard, ran the reference-passing handkerchief task on seeds 42/43/44, prompt version 3, code label \nolinkurl{3e316b4c-dirty}, and a 120-second wall limit. It completed \textbf{0/3}, made partial progress on two seeds, and ended \nolinkurl{agent-stopped} on all three after repeated text-only turns. Calls/invalid calls were 8/3, 4/3, and 6/3. All three trajectories passed replay. Its five-question closed-book quiz scored \textbf{0/5}. This validates two measurement paths on one model/task; it does not identify whether knowledge or tool use caused failure.

A Qwen2.5-14B seed-42 attempt was killed at a 180-second wall limit and labeled \nolinkurl{harness-crash (exit null)}. A partial seed-43 trace also exists after the interrupted scheduling attempt; there is no complete result for it, and seed 44 has no completed result. The attempted run is excluded from model denominators. The fallback's zero calls are not a measurement of the actual partial trajectory. The timeout label requires repair before formal evaluation.

Older repository notes report external Claude Sonnet 9/9 versus local Qwen 0/9 on a three-task pilot, B 0/3 versus C 1/3 on a first-meeting pilot, and 2/3 on a one-life island variant. These are historical, differently versioned records, not additional results in the present denominator or causal ablations. The reported GPT-6 Astra playthrough with roughly 22 hours of footage allowed walkthrough use, rollback, and human strategy discussion; it is development context rather than an independently scored benchmark episode. Model identity and the modifier-free claim require an archived playthrough manifest before use as research evidence.

\subsection{Medicine and monkey observation/goal audit}

The two audited tasks are \nolinkurl{classic10-baihe-medicine} and \nolinkurl{classic31-banana-monkeys}. The original B observation reduced some plants and animals to generic navigation labels, omitting cues visible in the rendered game. The audit first forwarded \nolinkurl{observe(full=true)} correctly so expanded inventory/state could be requested, and corrected item feedback that suggested interaction while dialogue was still open. The monkey goal previously accepted an opening banana-offering line before passage was actually clear. The revised goal requires event object 3482 in scene 192 to reach state 0; the reference now takes 23 calls rather than the prematurely accepted 22.

A subsequent appearance repair shares a reviewed catalog between local \nolinkurl{observe} and scene-wide \nolinkurl{map}. It matches MGO sprite bytes by SHA-256 and MAP/GOP background pairs by their hashes. Coverage is \textbf{64 sprite resources and nine map/background pairs} from both reference routes, including non-goal objects. Captions describe broad leaves and hanging yellow curved fruit, a small tree with reddish-orange round fruit, a water bank, a brown antlered deer, and a circular toothed metal object. They do not name a quest purpose, required offering, reward, or action order. Briefs were unchanged. This supplies visible evidence without explicitly stating the solution.

The catalog is a manually reviewed static/first-frame abstraction, not a runtime vision model or all-game coverage. Unknown or replaced content falls back to neutral descriptions; the lookup assumes immutable assets within a process. Background landmarks matter because some interactive locations have no individual sprite. Scene-wide \nolinkurl{map} can expose cues beyond the local observation; availability there does not prove every agent queried or used them. Unreviewed routes and dynamic states remain limitations.

These repairs live in a separate audit worktree based at \nolinkurl{3e316b4c}; they are not installed in the main working tree described in Section 5.1. Real-agent comparisons used frozen copies of the previous controlled runtime, adding appearance rendering without changing its engine build. Separate native/source-build checks guard the implementation. A detached copy has a null Git label; explicit source/build/asset/save/task manifests, not the base commit alone, identify the experiment.

\subsection{Budget calibration and protocol deviations}

Fable via the same external CLI used game seeds 43/44 for action-budget calibration. At the original medicine cap of 120, seed 43 exhausted the budget and seed 44 succeeded in 111 calls. Two fresh medicine episodes at a 240-call cap succeeded in \textbf{146 and 125 calls}, with 11 and three invalid calls. Monkey calibration succeeded in \textbf{48 and 46 calls}, both with zero invalid calls, under an 80-call cap. Thus six calibration episodes comprise five successes and one failure, all replay-verified; they are not six independent successes or an unbiased success estimate.

The predeclared call rule retained a budget if repeated success left at least 25\% spare calls; otherwise it selected a round ceiling at least 1.5 times observed successful exploration calls. Medicine was set to \textbf{240 calls}, at least 1.5 times 146, and monkey remained \textbf{80 calls}, with 40\% spare relative to 48. Virtual-time limits remained 3,600 and 1,800 seconds. These small, single-agent calibration samples justify provisional budgets, not a guarantee for every model.

The initial medicine token reserve was 2,880,000. During seed-42 evaluation, Nemotron stopped at 216 calls on that token cap. This episode is retained as an \textbf{excluded token-budget diagnostic}, not a completed 240-call failure. A measured built-in turn peak of 20,533 tokens motivated a 32,000-token-per-allowed-call safety reserve: medicine v4 uses \textbf{7,680,000 tokens}, with calls/time unchanged. This correction occurred after observing evaluation data; seed 42 is held out for the action-cap decision, not a pristine untouched test set for the full protocol.

One fresh Nemotron medicine episode was then run. The other three medicine episodes had already reached 240 calls under v3. Deterministic v3/v4 checks found identical initial observation, tool responses, and game outcomes for those fixed trajectories; the original model usage and task-version records remain intact. These checks are retrospective policy-invariance diagnostics, \textbf{not new model samples or evidence of equivalent external token enforcement}. Monkey v3 retains 960,000 tokens for built-in agents. CLI token caps are not incrementally enforced: Fable reported 12,055,420 medicine tokens and 2,866,716 monkey tokens, including cached input. The experiment is matched on game action limits, not equal token use or compute.

The counterfactual ablation uncovers two fundamental insights:
\begin{enumerate}
\item \textbf{Two-layer prior structure versus "Newtonian" scientific induction}: Stripping first-layer \textbf{walkthrough meta priors} (\nolinkurl{Jiushen}, \nolinkurl{Qian Kun Yi Zhi}, \nolinkurl{Yingu}) does not incapacitate \nolinkurl{GPT-6.1-Sol} or \nolinkurl{Gemini 4 Argon}, because their second-layer \textbf{domain mechanics priors} immediately prune futile instant-KO/paralysis tests and prioritize protective mitigation, achieving victory on \textbf{Attempt 2 (176 and 114 calls)} in 37.00 and 39.00 rounds. In the 1995 DOS combat engine, each round separates command collection (\nolinkurl{SelectAction}) from batch execution (\nolinkurl{PerformAction}): when slot-1 Li Xiaoyao (step \nolinkurl{t}) and slot-2 Zhao Ling'er (step \nolinkurl{t+1}) submit commands, the round has not yet executed, so observed boss HP delta is identically \nolinkurl{0}; only after slot-3 A'nu (step \nolinkurl{t+2}) submits her command does the engine execute all three actions and return the coupled round total \nolinkurl{ΔHP_round = x1 + x2 + x3}. Treating delayed batch feedback as atomic step-by-step feedback, \nolinkurl{DeepSeek V4.1 Flash} observed \nolinkurl{ΔHP = 0} after slot 1 and slot 2 and concluded (\nolinkurl{Turns @696, @699}) that \textbf{Baiyue is 100\% immune to all attacks from Li Xiaoyao and Zhao Ling'er (\nolinkurl{Jianshen}, \nolinkurl{Tianjian}, \nolinkurl{Wushen}, \nolinkurl{Bingcan Gu} = 0 damage) and that only slot-3 A'nu deals damage}, abandoning two-thirds of its party's firepower and even expending three revive actions on the same downed ally within a single round (\nolinkurl{#477–#479}). In contrast, \nolinkurl{Claude Opus 5.5} (\nolinkurl{#58–#84}) explicitly designed \textbf{controlled-variable linear elimination experiments}---pairing one unknown skill per round with two fixed \nolinkurl{1,000}-damage \nolinkurl{Wuying Poison} throws (\nolinkurl{x_unknown + 1000 + 1000 = ΔHP}) or two zero-damage heals (\nolinkurl{x_attack + 0 + 0 = ΔHP})---to isolate the exact damage of \nolinkurl{Jianshen} (\nolinkurl{510}), \nolinkurl{Taishan Yading} (\nolinkurl{436}), \nolinkurl{Wanyi Shixiang} (\nolinkurl{472}), thrown \nolinkurl{Guiya Dao} (\nolinkurl{1,587}), and \nolinkurl{Bingcan Gu} (\nolinkurl{230–360}) within three rounds.

\end{enumerate}

\section{Discussion and Limitations}

\textbf{Construct and information validity.} Correct tool syntax, available clues, retained clues, recalled game knowledge, tool self-coding, and successful planning are different observations. Missing visual semantics and premature goal detection were environment defects. Repairs improve the measurement contract; they do not warrant attributing every later failure to the model. A stronger study needs observation/context ablations and independent failure annotation. The targeted studies in Sections 5.8--5.11 further demonstrate that: (1) when an environment exhibits chiral symmetry ambiguity or unobservable state, reasoning models lacking a metacognitive stopping rule can fall into 100K-token deductive loops, whereas a 1-step epistemic probe or an exogenous per-turn token circuit breaker resolves the ambiguity immediately; (2) in canonical game benchmarks, pretraining priors operate at two layers (surface walkthrough memorization and deep RPG mechanics priors), and partial or locally distorted surface priors (such as \nolinkurl{gourd#q4}'s false well-side memory) can induce confirmation bias and 80-step search stalls, requiring closed-book quizzes (\nolinkurl{bench quiz}) alongside counterfactual mechanism ablations (\nolinkurl{BENCH_STRIP_CHEESE=1}) to disentangle memorized speedruns, false-prior belief updating, and zero-shot scientific induction or episodic spatial graph reuse; and (3) under delayed batch execution (\nolinkurl{ΔHP_round = x1 + x2 + x3}), modeling the measurement instrument's temporal semantics and performing controlled-variable elimination is essential to avoid credit-assignment illusions. While \nolinkurl{--pure} mode removes white-box L1 pre-checks and static heuristic limits, it couples code synthesis and debugging skill with domain planning, requiring the paired E8 protocol for separation.

\textbf{Sampling and adaptation.} Calibration uses one external agent and two seeds. The exploratory evaluation in Section 5.5 uses one sample per task/model on a seed already used in earlier development comparisons; the token correction further uses evaluation feedback. While the diagnostic studies in Sections 5.8--5.11 add cross-seed replication (\nolinkurl{seed 43}), multi-tier budget expansion (\nolinkurl{120 → 240 → 320 → 560/700}), and in-context retry loops, they focus on four representative tasks. Selected difficult tasks and correlated seeds cannot unbiasedly estimate overall RPG competence, and no cultural or regional effect is identified. Synthetic saves and modified classic-save levels/cash also limit natural-play interpretations.

\textbf{Scaffolding and budgets.} CLI and built-in agents differ in context retention, token enforcement, and usage reporting. Equal call limits do not imply equal compute. Section 5.9 shows that a single hard call cap (\nolinkurl{120} calls) induces a truncation illusion that conflates thorough zero-shot village exploration (100\% completion in 143--176 calls) with genuine stagnation, while Section 5.8 shows that the per-turn output token ceiling (\nolinkurl{4,096} versus \nolinkurl{16,384}) directly alters reasoning-model trajectories. Under \nolinkurl{--pure} mode, a single \nolinkurl{run_code} invocation can dispatch dozens of underlying \nolinkurl{CMSG_*} commands inside the sandbox; comparisons against \nolinkurl{assist} mode must therefore report both top-level MCP tool calls and underlying L0 command counts (\nolinkurl{commandsSent}). Costs for cloud/local adapters are not consistently priced. Failed runs have no winning-round or success-efficiency statistic. Wall-time classification and eight current reference failures remain release blockers.

\textbf{Reproduction and release.} A replay establishes action/outcome consistency in its recorded environment, not reproducibility of cloud generation or validity across engine updates. General tasks need explicit manifests beyond Git labels. The accompanying evidence index contains extracted numbers, provenance, and hashes; full traces and frozen runtimes currently reside in local ignored directories and have not been publicly archived. Proprietary assets and music are not proposed for redistribution; asset rights and release permissions need review. Public references increase contamination risk, and a hidden test set is not yet implemented.

\section{Conclusion}

Agent-PAL-Bench provides a working protocol and task collection for text-mediated decisions in a Chinese RPG, supporting both a built-in high-level semantic tool layer (\nolinkurl{assist} L1) and a low-level protocol plus dynamic self-coding layer (\nolinkurl{--pure} L0). The current evidence supports partial reference feasibility, a local end-to-end pilot, a documented two-task observation/goal audit, and a three-agent end-to-end \nolinkurl{--pure} completeness validation in which Argon, GPT-6.1-Sol, and Claude Opus 5.5 independently synthesized 731-line, 135-line, and 1,427-line runtime libraries to complete the entire game from new game to final credits (\nolinkurl{Slots 1–99}). Complementary multi-model behavioral and counterfactual ablation studies on the Dali Rain Altar (\nolinkurl{classic48-rain-orbs}), Baihe Village Medicine (\nolinkurl{classic10-baihe-medicine}), Final Boss Baiyue (\nolinkurl{baiyue-single-origin}), and the Yangzhou Purple Gold Gourd detective chain (\nolinkurl{classic19-yangzhou-gourd}) demonstrate that effective agency depends not only on static reasoning depth, but on issuing 1-step epistemic probes when pure deduction hits symmetry limits, balancing exhaustive zero-shot exploration against fast-pivoting elasticity, rapidly falsifying locally distorted pretraining priors while re-purposing cross-scene episodic spatial graphs, accumulating invariants monotonically across retries rather than overcorrecting to recent failures, and applying controlled-variable elimination to untangle delayed batch-execution feedback. A frozen release, repaired references, controlled scaffolding, independent samples, and a held-out evaluation remain necessary before comparative capability, tool-layer, or cultural-knowledge conclusions.
